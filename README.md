# 10-Minute Worksheets

Static site for the Binary Star worksheet series (computer vision and image processing),
published at <https://ai-gen1991.github.io/>.
Everything here is generated by `../build_site.py`; edit that script, not the `.html` files.

## Pages

- `index.html`: the course. Students sign in with Google, tick worksheets as done,
  watch lectures, like and comment on them, and open the view-only Practice Book. Ember, the pixel dragon, cheers them on.
- `contact.html`: signed-in students send feedback to the teacher.
- `privacy.html`: what is stored and who can see it.
- `admin.html`: the class dashboard (progress, reactions, messages). Only the course
  admin's Google account can read the data; this is enforced by the Firestore rules.

## Update the site

1. Add or change a worksheet folder (`AXX_Topic/` with its `.tex` and `.pdf`). The `.tex` is the
   source: each sheet has a picture page (`%% SEE-PAGE` or `%% ARCH-PAGE` block) before its
   practice page. Compile it twice with pdflatex.
2. In `MODULES` inside `build_site.py`, replace the topic's title with its worksheet number.
3. Run `python3 build_site.py`, then commit and push this folder.

## Data and security

Sign-in, progress, likes and messages use Firebase (project `practice-minutes-worksheets`).
The database rules live in `../firestore.rules`; after changing them, publish them in the
Firebase console (Firestore Database > Rules). Every page carries a Content Security Policy.

The Firebase web API key only works from these addresses (Google Cloud console >
APIs & Services > Credentials > Browser key > Website restrictions):
`https://ai-gen1991.github.io/*`, `https://binarystarchallenge.github.io/*` (planned new address),
`https://practice-minutes-worksheets.firebaseapp.com/*`
and `http://localhost:8000/*`. If the site moves to a new address, add it there and in
Firebase Authentication > Settings > Authorized domains.

Ember is an original character drawn for this site.
