# 10-Minute Worksheets

Static site for the Binary Star worksheet series (computer vision and image processing).
Everything here is generated by `../build_site.py`; edit that script, not `index.html`.

## Update the site

1. Add or change a worksheet folder (`AXX_Topic/` with its `.tex` and `.pdf`).
2. Add its number to a module in `MODULES` inside `build_site.py` (optional; unlisted
   worksheets appear under "More worksheets").
3. Run `python3 build_site.py`, then commit and push this folder.

## Visit, like and click counts

GitHub Pages cannot count anything by itself. The page is wired for GoatCounter:

1. Create a free site at <https://www.goatcounter.com> and note its code.
2. In GoatCounter settings, enable "Allow adding visitor counts on your website".
3. Set `GOATCOUNTER_CODE = "yourcode"` in `build_site.py` and rebuild.

The dashboard then shows page visits plus three events per worksheet:
`pdf-a01` (worksheet opened), `video-a01` (lecture played) and `like-a01` (liked).
Like counts and the total visit count are also shown on the page.
